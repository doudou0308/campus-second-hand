# XX大学校园二手交易平台

XX大学校园二手交易平台，专为在校师生打造的闲置物品流转网站。

## 项目结构

```C
├── css/
│   └── style.css          # 样式表
├── js/
│   └── script.js          # 表单验证脚本
├── img/
│   ├── DSC00355.jpg       # 首页横幅图
│   ├── DSC00371_1.jpg     # 备用图片
│   └── DSC00454.jpg       # 备用图片
├── index.html             # 首页
├── fabu.html              # 发布闲置
├── fenlei.html            # 分类浏览
├── xuzhi.html             # 交易须知
├── wenti.html             # 常见问题
├── wode.html              # 我的发布
├── lianxi.html            # 联系我们
├── guanyu.html            # 关于我们
└── README.md
```

## 页面说明

| 页面   | 文件          | 说明                      |
| ---- | ----------- | ----------------------- |
| 首页   | index.html  | 平台入口，横幅大图、热门分类、热门商品、侧边栏 |
| 发布闲置 | fabu.html   | 发布二手物品，含表单验证            |
| 分类浏览 | fenlei.html | 按类别浏览商品，共五大类30件         |
| 交易须知 | xuzhi.html  | 交易流程、安全指南、违规物品清单        |
| 常见问题 | wenti.html  | FAQ问答列表                 |
| 我的发布 | wode.html   | 查看和管理已发布物品              |
| 联系我们 | lianxi.html | 用户留言表单，含邮箱格式验证          |
| 关于我们 | guanyu.html | 平台介绍与特色说明               |

## 技术栈

- HTML5
- CSS3（Flex 弹性布局）
- JavaScript（原生表单验证）

## 设计说明

- 主色调：#052659（深蓝）、#5483B3（蓝灰）、#C1E8FF（浅蓝）
- 页面宽度：1200px 定宽居中
- 布局方式：Flex 弹性布局
- 导航栏和页脚在所有页面中保持一致
